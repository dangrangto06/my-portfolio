## 📌 About The Project

This is the source code for my personal portfolio website, inspired by modern glassmorphism web aesthetics. It showcases my academic coursework, technical competencies in **React.js & Java Spring Boot**, hands-on **Software Quality Assurance (QA)** workflows, and featured projects.

### 🚀 Key Features

- **Futuristic Dark Glassmorphism Design**: Sleek animated background shapes, rotating gradient avatar rings, and floating skill badges.
- **Dual Focus - Dev & QA**: Showcases both frontend engineering and manual software testing (Test Case design, API testing via Postman, and Jira bug tracking).
- **Interactive Project Showcases**: Modal dialogs displaying project architectures, database schemas, and contributions.
- **Responsive & Performance Optimized**: Mobile-first responsive layout with Google Fonts Outfit and JetBrains Mono.
- **Interactive Micro-Interactions**: Filterable skill chips, animated counter stats, copy-email toast notifications, and smooth scroll.

## 🌐 Deploy to GitHub Pages

1. Push this repository to GitHub.
2. Go to **Settings** → **Pages**.
3. Under **Branch**, select `main` and folder `/(root)`.
4. Click **Save**. Your site will be live at:
   `https://<your-username>.github.io/<repository-name>/`
